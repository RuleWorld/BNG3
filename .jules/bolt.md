## 2026-10-06 - Optimization of deepcopy operations using custom __new__ methods
**Learning:** In the Atomizer codebase, replacing slow `copy.deepcopy()` calls on complex objects (like `Molecule`, `Species`, `Component`) requires custom `.copy()` methods. Critically, to avoid triggering expensive or incorrect side-effects in `__init__` (such as random hash generation using numpy, or unnecessary list allocations), it is best to instantiate the copy using `Molecule.__new__(Molecule)` and then explicitly set all required attributes, including dynamically assigned properties like `trueName` and `uniqueIdentifier`.
**Action:** When replacing `deepcopy` on custom classes, inspect `__init__` for side effects. Use `__new__` to bypass initialization, then manually assign state, ensuring all properties accessed by the application are preserved.
