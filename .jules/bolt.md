## $(date +%Y-%m-%d) - Object instantiation and regex compilation bottlenecks in Atomizer
**Learning:** In highly recursive object structures like `Molecule` and `Component` inside the atomizer, standard copying logic (even with explicit field copying) incurs heavy overhead due to Python's `__init__` calls and method resolution. Additionally, inline string interpolation in tight loops for `re.compile()` (e.g., `re.compile(rf"\b{re.escape(function)}\s*\(")`) causes significant overhead even if Python internally caches regexes, because the formatting and escaping runs every iteration.
**Action:** Use `__new__` and `__dict__.update()` for fast copying of simple objects without `__init__` overhead. Create explicit dictionary-based memoization caches at the module level for regexes compiled with dynamic values inside tight loops.
