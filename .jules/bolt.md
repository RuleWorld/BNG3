## 2025-02-23 - Performance optimization - replace deepcopy with .copy()
**Learning:** Python's copy.deepcopy() in python/bionetgen/atomizer (Molecule, Species, Component) is a major performance bottleneck. Do not replace it with shallow copies, as this causes mutated shared state. Instead, use custom .copy() methods on these objects (which safely implement deep copying internally), use explicit list comprehensions or list() for primitive lists (like bonds and states), and use direct assignment for immutable string attributes.
**Action:** When working with deep copies of objects that implement custom .copy() methods explicitly avoiding shallow copying (e.g. returning a new object and doing shallow copying/list comprehensions within it), prefer to call .copy(). This yields a large performance benefit and prevents errors with copy.deepcopy().
