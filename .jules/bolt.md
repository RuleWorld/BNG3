## 2024-06-25 - Python deepcopy bottleneck in atomizer structures
**Learning:** Python's `copy.deepcopy()` is highly inefficient when called recursively on complex objects like `Species`, `Molecule`, and `Component` in `python/bionetgen/atomizer`. However, blindly replacing `deepcopy()` with `.copy()` causes `AttributeError` if the object doesn't have a built-in `.copy()` method or if the existing `.copy()` method misses copying dynamically added attributes (like `uniqueIdentifier`, `trueName`, `compartment`, or `bondNumbers`).
**Action:** Always inspect the implementation of custom `.copy()` methods on Python objects to ensure they explicitly copy all state attributes (including dynamic ones via `getattr()`) before replacing `deepcopy()`. Use explicit `list()` mapping for basic arrays inside these methods to avoid O(N) overhead.
