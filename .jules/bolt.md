## 2024-05-19 - [Optimize shallow copying using __dict__.update in Python]
**Learning:** Python's `copy.copy(self)` and `copy.deepcopy()` have a significant overhead compared to manually bypassing `__init__` dispatch. Using `cls.__new__(cls)` and `__dict__.update(self.__dict__)` is a well-known Python performance optimization for class cloning, bypassing standard deep/shallow copy bottlenecks in the Atomizer logic (especially critical for heavily manipulated objects like `Molecule`, `Species`, `Component`).
**Action:** When working on heavily cloned classes in performance critical modules, avoid `copy.copy(self)` and use `__new__` combined with `__dict__.update` for rapid state duplication, while being mindful to manually clone inner collections that shouldn't be shared.
