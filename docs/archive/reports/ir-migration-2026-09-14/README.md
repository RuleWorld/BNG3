# Archived IR-migration reports

This directory contains historical reports and package metadata imported with
the BNG3 IR-migration snapshots. They preserve the state and provenance of
those snapshots; they are not current execution instructions.

Use the live documents for current work:

- [`CURRENT_PROGRESS.md`](../../../CURRENT_PROGRESS.md) — current evidence and
  next actions.
- [`BNG3_CONVERGENCE_DONE_CHECKLIST.md`](../../../BNG3_CONVERGENCE_DONE_CHECKLIST.md)
  — authoritative completion criteria.
- [`BNG3_INTEGRATION_PLAN.md`](../../../BNG3_INTEGRATION_PLAN.md) — architecture
  and phased work plan.
- [`validation/README.md`](../../../validation/README.md) — validation commands
  and oracle boundaries.

## Archived contents

- `CURRENT_RECONSTRUCTION_STATUS.md` — reconstructed-source snapshot status.
- `FORMALIZATION_REPORT.md` — Lean formalization milestone report.
- `IR_MIGRATION_IMPLEMENTATION_RECORD.md` — detailed IR migration record.
- `README_IR_MIGRATION_ELI15.md` — explanatory IR migration guide.
- `VALIDATION_STATUS_IR_MIGRATION.md` — packaging-environment validation
  status from 2026-09-11.
- `IR_MIGRATION_DIFFSTAT.txt` and `IR_MIGRATION_METRICS.txt` — snapshot
  metadata.
- `BNG3_overcount_analysis.md` — historical network-overcount investigation;
  its conclusions are not current parity evidence.

The former root-level package wrapper files and patch files were removed on
2026-09-14 after their changes had been applied to the repository. The
resulting source, tests, validation references, and provenance records are the
authoritative forms now.
